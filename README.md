# DT Trinethra Analyzer

This project is being built for the DT CultureTech Software Developer recruitment assignment.

## Goal

Build a local AI-powered web application that analyzes supervisor feedback transcripts and generates structured psychological review insights.

## Tech Stack

- React + Vite
- Node.js + Express
- Ollama (llama3.2)
- Local LLM inference
